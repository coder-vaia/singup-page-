# Signup Page

A clean and responsive signup page built with HTML and CSS.

## Overview

This project contains a user-friendly signup form designed to collect user information with a modern, responsive design. The page is lightweight, requiring no external dependencies or build tools.

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Clean UI** - Minimalist and intuitive user interface
- **HTML & CSS Only** - No frameworks or dependencies required
- **Easy to Customize** - Simple structure for quick modifications

## File Structure

```
signup-page/
├── index.html
├── style.css
└── README.md
```

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive layouts

## Getting Started

### Prerequisites

No installation or setup required! You only need a web browser.

### Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/signup-page.git
   ```

2. Navigate to the project directory:

   ```bash
   cd signup-page
   ```

3. Open `index.html` in your web browser by either:
   - Double-clicking the `index.html` file, or
   - Right-clicking and selecting "Open with" → your preferred browser

That's it! The signup page is now ready to use.

## Customization

You can easily customize the form by editing:

- **Colors** - Modify CSS variables or color values in `style.css`
- **Form Fields** - Add or remove input fields in `index.html`
- **Typography** - Update font families and sizes in `style.css`
- **Layout** - Adjust spacing and dimensions in the CSS file
